    Phones

      Anyone with this link can open the door. Send it only to the person who’ll use it, and remove their phone here if it’s lost.

      Code at the lobby panel

      Press the call button in a pattern of short and long presses, and the door opens. Every press still rings, so pick something nobody presses by accident.

      Open with a code

      A press in between short and long counts as neither, so the code fails. Not sure where yours fall? Press the lobby button a few times, a couple of seconds apart, and look at Activity: it shows how long each press was. While the code is on, presses show up once they stop: a wrong code as its pattern, the right one as the door opening.

      Remote access

      Through an MQTT broker, so phones can open the door from anywhere. Set-up guide: docs/remote-access.md.
